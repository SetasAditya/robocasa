# Robot assets

These are the deployed RoboVision CoBot base and linked 2F85 hand assets. The
hand keeps its collision geometry, equalities, contacts, tendon and actuator;
only file references were made relative. The camera housing and chassis meshes
are the deployed CoBot geometry. Kinova arm assets are provided by robosuite.

The seven Robotiq meshes originate from the ROS-Industrial Robotiq description
via the MuJoCo Menagerie 2F85 model used by RoboLab. Their original copyright
and BSD-2-Clause terms are retained in `robotiq_2f85/LICENSE`.
